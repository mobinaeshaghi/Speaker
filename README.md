# Speaker

گزارش کار ازمایش speaker

نام و نام خانوادگی:مبینا اسحاقی

استاد:اقای دکتر عباسی

عنوان آزمایش: استفاده از اسپیکر و کلید برای تولید صدا


هدف آزمایش:
 هدف از این آزمایش یادگیری نحوه استفاده از کلید برای فعال‌سازی اسپیکر و تولید صدا است.

وسایل مورد نیاز:

برد آردوینو (Arduino Uno) 💻

اسپیکر🎶

کلید (Push Button) 🔲

سیم‌ها 🔌

لپ‌تاپ یا کامپیوتر برای برنامه‌نویسی آردوینو 💻

نرم‌افزار آردوینو IDE 🖥️


شرح آزمایش:

اتصال قطعات:

کلید به یکی از پایه‌های دیجیتال آردوینو (مثلاً 2) وصل می‌شود.

اسپیکر (یا بیزر) به یکی از پایه‌های دیجیتال آردوینو که برای تولید صدا مناسب است (مثلاً 9) وصل می‌شود.

پایه منفی اسپیکر به پایه GND آردوینو وصل می‌شود. 🔴


عملکرد:

هنگامی که کلید فشرده می‌شود، سیگنالی به آردوینو ارسال می‌شود که باعث فعال شدن اسپیکر و تولید صدا می‌شود.

وقتی کلید رها می‌شود، اسپیکر خاموش می‌شود.

نتیجه‌گیری: این آزمایش به شما کمک می‌کند تا با استفاده از کلید به‌سادگی یک اسپیکر را کنترل کرده و با فشردن کلید، صدا تولید کنید. این سیستم می‌تواند در پروژه‌هایی مانند آلارم‌ها، هشدارها یا هرگونه کاربردی که نیاز به تولید صدا با ورودی کلید دارد، استفاده شود.
